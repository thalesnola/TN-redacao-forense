# Templates de tabela — eixo DECLARADO × OBSERVADO/CONSTATADO

Modelos de quadros analíticos para análise patrimonial, no eixo efetivamente medido no acervo
(ver `skills/redacao-forense/references/metodologia-patrimonial.md`). **Não usar "Fórmula do
Crédito Descoberto" como termo fixo** — o conceito e o vocabulário abaixo são os que aparecem
de fato nas peças verificadas.

Ao introduzir o conceito pela primeira vez numa peça, definir com fonte (ver METODOLOGIA no
`templates/modelo-ipj-instituicao-completo.md`), nunca como jargão pressuposto.

## 2. Bens declarados × patrimônio observado/constatado

| Ano-calendário | DECLARADA — sobra financeira | DECLARADA — a descoberto | OBSERVADA/CONSTATADA — sobra | OBSERVADA/CONSTATADA — a descoberto |
|---|---|---|---|---|
| [AAAA] | | | | |
| **TOTAL** | | | | |

```
sobra financeira        = rendimentos líquidos − despesas − aumento do patrimônio líquido
acréscimo a descoberto  : renda líquida < acréscimo patrimonial
```

A tabela roda nas **duas visões lado a lado** — é o contraste entre a coluna DECLARADA (que
tende a fechar ou ficar levemente negativa) e a coluna OBSERVADA/CONSTATADA (que explode no
ano em que entram os bens localizados por telemática e vigilância) que sustenta a conclusão,
não o valor isolado.

Quando não houver dado do exercício, escrever a razão, nunca deixar em branco:
*"Não disponível"* (não houve entrega da declaração — diferente de patrimônio zero).
